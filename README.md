# Rafael's Portfolio

A modern, responsive portfolio website showcasing projects and skills built with Angular.

**Live:** https://rafael-portfolio-delta.vercel.app

## 🛠️ Tech Stack

- **Frontend Framework:** Angular 21
- **Styling:** SCSS
- **Language:** TypeScript
- **Build Tool:** Angular CLI
- **Testing:** Vitest (unit tests), e2e testing framework
- **Deployment:** Vercel

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/RafaelPalomares/rafaelPortfolio.git
cd rafaelPortfolio

# Install dependencies
npm install
```

### Development

```bash
# Start development server
npm run ng serve
# or
ng serve
```

Navigate to `http://localhost:4200/`. The application will automatically reload when you modify source files.

### Build

```bash
# Build for production
npm run ng build
# or
ng build
```

Build artifacts are stored in the `dist/` directory.

## 🧪 Testing

### Unit Tests

```bash
# Run unit tests with Vitest
npm run ng test
# or
ng test
```

### End-to-End Tests

```bash
# Run e2e tests
npm run ng e2e
# or
ng e2e
```

## 📦 Project Structure

```
src/
├── app/              # Angular components and modules
├── assets/           # Static assets (images, fonts, etc.)
├── styles/           # Global SCSS styles
└── index.html        # Main HTML file
```
